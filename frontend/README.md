# Hacker House Goa 2026 — Frontend

Editorial tropical event website for HH Goa 2026, built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — hero, challenge, building, timeline, notice board, leaderboard, FAQ |
| `/timeline` | Key dates timeline |
| `/tasks` | Task listing |
| `/tasks/voice-enabled-rag` | Voice-Enabled RAG task detail |
| `/notice-board` | Pinned notice cards |
| `/faq` | FAQ accordion |
| `/register` | Registration form |
| `/submit` | Project submission |

## Design System

- **Colors:** Forest green `#003D2B`, parchment `#F7F0DD`, gold `#F5C51B`, pink `#F00072`
- **Fonts:** Cormorant Garamond (display), Inter (UI/body)
- **Style:** Editorial magazine + Goan tropical poster art
